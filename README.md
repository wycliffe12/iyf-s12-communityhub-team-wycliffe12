# CommunityHub

**Tagline: Connect. Share. Grow Together.**

## 1. Project Overview

CommunityHub is a web-based community networking application designed to bring people together in one digital space where they can communicate, share information, exchange ideas and support one another.

The application provides a platform where community members can create and view posts and interact with a shared community environment.

## 2. Project Objectives

- To provide a platform for community members to connect.
- To enable users to share ideas and information through posts.
- To encourage communication and collaboration.
- To create an accessible and user-friendly community platform.

## 3. Main Features

- **Shared Layout:** Header, sidebar navigation and footer.
- **Posts Management:** Create and display community posts.
- **Post Components:** Individual post cards and a post list.
- **Utility Functions:** Helper functions for post validation, initials and date formatting.

Additional planned features include user profiles, comments and user authentication.

## 6. Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Clone the repository

```bash
git clone https://github.com/wycliffe12/iyf-s12-communityhub-team-wycliffe12.git
```

### Navigate to the frontend folder

```bash
cd iyf-s12-communityhub-team-wycliffe12/frontend
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 7. Testing

Run automated tests using:

```bash
npm test
```

Create a production build using:

```bash
npm run build
```
